addons.txt: lista de addons que o pacote carrega quando NAO ha conta (modo local).
Formato: nome<TAB>url-do-manifest.json  (uma linha por addon).
Cinemeta = dados de filme/serie. OpenSubtitles = legendas.
Para achar fontes de video, adicione aqui (ou pelo app: Configuracoes > Addons) a URL
do manifest.json de cada addon de stream que voce usa.
